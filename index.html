Carregando anúncios…

Dados do Meta Ads puxados pelo Windsor.ai a cada vez que a página é aberta. Os números mais recentes podem levar algumas horas para chegar (depende do plano do Windsor); campanhas e anúncios novos aparecem assim que tiverem a primeira entrega. A comparação usa o mesmo número de dias logo antes do período escolhido. Leads = conversas iniciadas no WhatsApp (pessoas sem contato há 7+ dias) + cadastros em formulário. Vendas e faturamento = compras registradas pelo Meta (pixel, API de Conversões ou WhatsApp). Painel QH4.
